# نقل الملفات بكود لمرة واحدة (File Transfer)

موقع بسيط لنقل الملفات (إكسل، وورد، صور...) بين جهازين على أي شبكة — لا يشترط أن
يكونا على نفس الشبكة المحلية.

## كيف يعمل

1. المُرسِل يرفع الملف من صفحة "إرسال ملف"، فيحصل على **كود من 6 خانات**.
2. المُرسِل يشارك الكود (بأي وسيلة: واتساب، رسالة...) مع المستلم.
3. المستلم يفتح الموقع من أي جهاز/شبكة، يكتب الكود في "استلام ملف"، فيتحمّل
   الملف مباشرة.
4. بمجرد أول تحميل ناجح، **يُحذف الملف تلقائيًا** ويصبح الكود غير صالح
   (استخدام لمرة واحدة).

لا يوجد تسجيل دخول ولا قاعدة بيانات منفصلة — التخزين والبحث عن الملف يعتمدان
كليًا على [Vercel Blob](https://vercel.com/docs/storage/vercel-blob)، حيث
يُحفظ الملف تحت المسار `transfers/<الكود>/<اسم الملف>`، وحذف ذلك المسار بعد
التحميل هو ما يحقق "الاستخدام لمرة واحدة".

## المتطلبات

- حساب [Vercel](https://vercel.com) (مجاني).
- تفعيل **Blob Store** على مشروعك في Vercel:
  Project → Storage → Create Database → Blob.
  بمجرد إنشائه تُضاف تلقائيًا متغيّرات البيئة (منها `BLOB_READ_WRITE_TOKEN`)
  لمشروعك على Vercel، ولا حاجة لإعدادها يدويًا في الإنتاج.

## التشغيل محليًا

```bash
npm install
vercel link      # اربط المجلد بمشروعك على Vercel (مرة واحدة)
vercel env pull  # يسحب متغيرات البيئة (BLOB_READ_WRITE_TOKEN) إلى .env.local
npm run dev
```

افتح `http://localhost:3000`.

> بدون `BLOB_READ_WRITE_TOKEN` لن يعمل الرفع أو التحميل محليًا، لأن التخزين
> فعليًا على Vercel Blob وليس على القرص المحلي.

## النشر على Vercel

```bash
vercel deploy --prod
```

أو ببساطة اربط الريبو بمشروع على [vercel.com/new](https://vercel.com/new) وفعّل
Blob Store كما بالأعلى — كل push على الفرع المربوط سينشر تلقائيًا.

## البنية

- `app/page.js` — الواجهة (إرسال/استلام).
- `app/api/code/route.js` — يولّد كودًا فريدًا من 6 خانات.
- `app/api/upload/route.js` — يمنح المتصفح إذنًا آمنًا للرفع المباشر إلى
  Vercel Blob (بدون المرور بحدود حجم الطلب في السيرفرلس).
- `app/api/download/[code]/route.js` — يبحث عن الملف بالكود، يبثّه للمستخدم،
  ثم يحذفه فورًا لتحقيق الاستخدام لمرة واحدة.
- `lib/code.js` — توليد/التحقق من صيغة الكود.

## ملاحظات

- الحد الأقصى الحالي لحجم الملف الواحد هو 200MB (قابل للتعديل في
  `app/api/upload/route.js`)، وقد يخضع أيضًا لحدود خطة Vercel Blob المجانية.
- الكود عشوائي (6 أحرف/أرقام مع استبعاد الرموز المتشابهة بصريًا مثل 0/O و1/I)،
  وصالح للاستخدام مرة واحدة فقط ثم يُحذف الملف نهائيًا.
